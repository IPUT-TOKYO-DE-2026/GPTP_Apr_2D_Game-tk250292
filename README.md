# Capsule Shooter

## ゲームの内容
画面の左右から飛んでくるカプセル状のブロックにボールをぶつけてハイスコアを目指そう！

## 操作説明
- ボールをひっぱって飛ばす方法
- ボールにカーソルを合わせてクリック（ボールの少し手前をクリックするのがコツ）　→クリックしたまま、飛ばしたい方向と逆の方向に引っ張る　→ガイドに従って狙いを定め、クリックしている指を離す
